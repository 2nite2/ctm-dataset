# Decomponentized Samples

This directory stores Vue single-file components generated by inlining child component calls into parent components. These samples simulate cases where a region that was originally implemented as a separate component has been merged back into the parent file.

## Usage

- `manifest.json` records the parent sample, inlined child sample, original component call, and generated file path for each retained sample.
- `samples/<id>/meta.json` stores detailed metadata for each decomponentized sample.
- A generated file can be copied over the corresponding parent component in a test project before running cross-index tree construction and candidate ranking.
- The recorded source range identifies the complete reference region after child bindings, script logic, styles, and dependencies have been merged into the parent component.
